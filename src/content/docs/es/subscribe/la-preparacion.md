Una buena preparación es clave para un inicio exitoso con Tesoro CRM. Esta guía te ayudará a preparar tu organización para la implementación. Sigue estos pasos para organizarlo todo.

---

## Inventario

### 1. Equipo y Roles

:::warning
Asegúrate de que siempre haya al menos un Administrador para gestionar el sistema.
:::

Tesoro CRM tiene dos roles:

**Administrador**: Tiene los máximos privilegios y puede configurar ajustes empresariales, crear y invitar usuarios.

**Empleado**: Tiene los mismos privilegios que un administrador excepto en ajustes, no puede modificar configuraciones empresariales ni gestionar usuarios.

### 2. Migración de Datos

:::tip
Siempre haz una copia de seguridad de tus datos existentes antes de comenzar la migración.
:::

:::warning
Verifica cuidadosamente la integridad y precisión de los datos importados.
:::

Para migrar a Tesoro CRM, existen interfaces importantes:

**Contactos**

En Tesoro, los contactos se gestionan en una base de datos única y pueden clasificarse como Lead o Contacto:

- **Leads**: Aparecen en la interfaz de leads y se tratan como tal.
- **Contactos**: Cuando un lead se convierte en acuerdo y contacto, cambia a Contacto.

Usa la plantilla de importación de Tesoro (formato CSV) para estructurar correctamente los datos. La importación puede ser compleja; consulta con el Gestor de Éxito del Cliente de Tesoro para un plan de migración adecuado.

### 3. Flujos de Trabajo

- Documenta tus procesos actuales:
  - Gestión de leads
  - Flujo de acuerdos
  - Informes
  - Gestión documental

### 4. Conocimiento y Formación

- Revisa la documentación de Tesoro
- Organiza un seminario web con el Gestor de Éxito del Cliente

## Preparación Técnica

### 1. Verificación del Sistema

- Navegadores compatibles: Chrome, Firefox o Edge recientes
- Conexión a Internet estable
- Configuración correcta de correo electrónico

### 2. Integraciones

- Identifica integraciones necesarias:
  - Correo electrónico
  - Calendario
  - Almacenamiento documental
  - Portales inmobiliarios
  - Software financiero

### 3. Integración de Correo

:::warning
Verifica que tu proveedor de correo cumpla con los requisitos de Tesoro CRM.
:::

Tesoro soporta:
- Gmail for Business
- Microsoft Office 365

### 4. Portales Inmobiliarios y Feeds XML

:::tip
Prueba los feeds XML en entorno de prueba primero.
:::

- Conoce los tipos de feed XML utilizados
- Configuraciones específicas si son necesarias
