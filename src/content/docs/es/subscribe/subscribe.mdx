En esta sección encontrarás toda la información sobre las diferentes suscripciones y planes de precios de Tesoro.

## Suscribirse a Tesoro CRM

Los agentes inmobiliarios pueden registrarse fácilmente en Tesoro CRM, como se explicó anteriormente en la sección de registro. Cada agente recién registrado recibe 7 días de acceso gratuito a una versión completamente funcional de Tesoro CRM. No hay diferencia entre la versión de pago y la versión de prueba.

### 1. Período de prueba gratuito

- **Duración**: 7 días
- **Funcionalidad**: Idéntica a la versión de pago
- **Limitación**: Después de 7 días, el acceso a Tesoro CRM se bloquea hasta que se introduzcan los datos de pago y se realice el primer pago.
- **Los datos se conservan**: Si no se introducen los datos de pago, la cuenta seguirá existiendo y todos los datos introducidos se conservarán. Una vez completado el pago, se restaurará el acceso y se podrá seguir trabajando desde el último momento conocido.

### 2. Pago y Paquetes

- **Precio**: €99 por mes
- **Incluye**: Hasta 10 usuarios
- **Más de 10 usuarios**: Precio personalizado, contactar con Ventas de Tesoro

### 3. Proceso de pago

- **Método de pago**: Tarjeta de crédito (a través de Stripe)
- **Dónde encontrarlo**:
  1. Como Administrador, ve a Configuración de la Empresa
  2. Haz clic en Suscripciones y Planes
  3. Selecciona el Plan Predeterminado
  4. Sigue las instrucciones para el pago

### 4. Cancelación y Duración de la Suscripción

- **Pago por adelantado**: Las suscripciones siempre se pagan por adelantado.
- **Suscripción mensual**: Si se cancela, la suscripción permanece activa hasta el final del mes pagado.
- **Suscripción anual**: Si se cancela, la suscripción permanece activa hasta el final del año pagado.
- **Cambios en el tipo de suscripción**: Si un usuario cambia de una suscripción mensual a una anual (o viceversa), el nuevo período de suscripción solo se aplica después de que finalice el período de pago actual.

### 5. Visualizaciones

Para una incorporación fluida, se añadirán imágenes de:

- La página de configuración donde se pueden gestionar las suscripciones
- La pantalla de selección de suscripción

Después de un pago exitoso, la suscripción se activa inmediatamente y el CRM permanece completamente accesible.
